## 一、改造目标

将 MemeSeek 改造成一个“本地优先”的梗图管理网页：

- 用户第一次使用时，主动选择自己电脑上的一个“梗图文件夹”并授予网页读写权限。
- 后续导入、拖拽或粘贴的图片和视频直接写入该本地文件夹，不再永久上传到 MemeSeek 后端。
- 网页记住用户选择过的文件夹；权限仍然有效时自动进入，权限失效时只要求用户重新授权，尽量避免重新选择目录。
- MVP 不提供注册、登录、多用户账号、云端文件同步和跨设备同步。
- CloudBase 主要负责托管前端网页；后端只保留必要的 AI 临时分析能力。

## 二、目标用户体验

### 2.1 首次打开

```text
打开 MemeSeek
    ↓
显示“选择梗图文件夹”引导框
    ↓
用户点击“选择文件夹”
    ↓
浏览器打开系统目录选择器
    ↓
用户选择目录并授予读写权限
    ↓
MemeSeek 扫描目录并进入梗图库
```

说明：受浏览器安全限制，系统目录选择器必须由用户点击按钮后触发，不能在页面加载时自动弹出。

### 2.2 再次打开

启动时读取 IndexedDB 中保存的 `FileSystemDirectoryHandle`，并检查权限：

| 状态 | 页面行为 |
| --- | --- |
| 没有保存过目录句柄 | 显示“选择梗图文件夹” |
| 目录句柄存在且权限为 `granted` | 自动扫描目录并进入梗图库 |
| 目录句柄存在但权限为 `prompt` | 显示“继续访问该文件夹”，用户点击后重新授权，不重新选目录 |
| 权限为 `denied`、目录失效或句柄不可用 | 提示原因并要求重新选择目录 |

### 2.3 更换素材库

- 设置页提供“更换梗图文件夹”入口。
- 更换前必须明确提示：原文件夹中的文件不会被删除或自动移动。
- 用户确认后选择新目录，MemeSeek 扫描新目录并切换当前素材库。

## 三、产品边界

### 3.1 MVP 范围

- 桌面版 Chrome 和 Edge。
- HTTPS 环境，包括 CloudBase 静态网站托管域名和正式自定义域名。
- 图片格式：JPG、JPEG、PNG、GIF、WebP。
- 视频格式：MP4、WebM、MOV。
- 文件保存在用户授权的本地目录。
- 梗图元数据保存在所选素材库内的索引文件中。
- 目录句柄和必要的本地缓存保存在 IndexedDB。
- 搜索、编辑、删除和 AI 分析均围绕当前本地素材库工作。

### 3.2 明确不做

- 不做注册、登录、用户账号和用户权限系统。
- 不做 CloudBase 云存储/COS 永久文件存储。
- 不做多设备自动同步、文件冲突合并和协同编辑。
- 不保证 Firefox、Safari 和手机浏览器完整可用。
- 不允许用户通过输入 `D:\\xxx` 等路径直接授权；必须使用浏览器目录选择器。
- 不在服务器永久保存用户图片或视频。

## 四、本地素材库结构

用户可以选择一个已有目录。MemeSeek 不强制移动目录中原有文件，新导入的媒体默认写入目录根部。

```text
用户选择的梗图文件夹/
├── 原有或新导入的图片、GIF、视频
└── .memeseek/
    ├── index.json
    └── thumbnails/
```

- `.memeseek/index.json`：梗图标题、描述、标签、OCR、媒体信息和相对路径。
- `.memeseek/thumbnails/`：视频和动图的本地封面。
- 索引只保存相对路径，不能保存用户电脑上的绝对路径。
- IndexedDB 只保存目录句柄、当前素材库标识和可重建缓存，不作为元数据唯一来源。

建议的索引记录：

```ts
type LocalMemeRecord = {
  id: string;
  relativePath: string;
  thumbnailRelativePath?: string;
  mediaType: 'IMAGE' | 'VIDEO';
  mimeType?: string;
  title: string;
  description: string;
  tags: string[];
  ocrText: string;
  transcript: string;
  status: 'PROCESSING' | 'COMPLETED' | 'FAILED';
  errorMessage?: string;
  createdAt: string;
  updatedAt: string;
};
```

## 九、验收标准

满足以下条件才视为本地文件夹模式完成：

1. 新用户可以通过一次主动选择建立本地素材库。
2. 权限有效时，关闭并重新打开网页不需要重新选择文件夹。
3. 权限需要恢复时，用户只需点击“继续访问”，不需要重新定位目录。
4. 新导入的媒体文件确实出现在用户选择的本地目录中。
5. 列表、搜索、编辑、删除和刷新页面均不依赖 PostgreSQL。
6. AI 分析可以读取本地图片并返回结果，但服务器不会永久保存图片。
7. 没有登录、CloudBase 云存储或数据库时，核心梗图库仍然可用。
8. 不支持的浏览器和权限异常都有可理解、可恢复的提示。
